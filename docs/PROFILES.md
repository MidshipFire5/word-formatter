# Профили оформления

Профиль — это файл JSON с параметрами оформления. Добавление нового профиля
не требует изменений в коде приложения: достаточно положить файл в нужную папку.

## Где лежат профили

| Папка | Назначение |
|---|---|
| `profiles/` рядом с программой | встроенные профили, обновляются вместе с проектом |
| Windows: `%APPDATA%\WordFormatter\profiles` | личные профили пользователя |
| Linux: `~/.config/WordFormatter/profiles` | личные профили пользователя |

Точные пути печатает команда `python main.py --list-profiles`.

Правила:

- личный профиль с тем же `id`, что и встроенный, **заменяет** встроенный;
- профиль с новым `id` **добавляется** к списку;
- файл с ошибкой не ломает приложение: профиль показывается в списке
  с пометкой об ошибке и объяснением, что именно не так.

## Как создать свой профиль

1. Возьмите за основу `profiles/fu-krasnodar-2026.json` — в нём заполнены
   все поля.
2. Скопируйте его в папку личных профилей.
3. Измените `id` (латиница, цифры, точка, дефис и подчёркивание), `name`,
   `source` и параметры оформления.
4. Запустите приложение и выберите новый профиль в списке.

## Формат файла

### Общие поля профиля

| Поле | Тип | Обязательное | Описание |
|---|---|---|---|
| `id` | строка | да | Уникальный идентификатор: `^[a-z0-9][a-z0-9._-]{1,63}$` |
| `name` | строка | да | Название для списка в интерфейсе |
| `description` | строка | нет | Краткое описание |
| `version` | строка | да | Версия профиля: `1.0` или `1.0.0` |
| `demo` | логическое | нет | `true` — демонстрационный профиль (в списке появится пометка) |
| `source` | объект | нет | Источник требований: `title`, `authors`, `place`, `year`, `pages`, `note` |
| `appliesTo` | список строк | да | Виды работ, например «курсовая работа» |
| `limitations` | список строк | нет | Что профиль не делает — эти строки попадут в отчёт |

### Общие поля оформления абзаца

Используются в `body`, `headings.structural`, `headings.levels.*`
и `captions.*`:

| Поле | Тип | Обязательное | Значения |
|---|---|---|---|
| `font` | строка или `null` | нет | Название шрифта, например `Times New Roman` |
| `sizePt` | число | да | Размер шрифта в пунктах, 6–72 |
| `bold` | логическое | нет | Полужирный |
| `italic` | логическое | нет | Курсив |
| `color` | строка или `null` | нет | Цвет текста в виде `#1A2B3C`; `null` — не менять |
| `alignment` | строка | да | `left`, `center`, `right`, `justify` |
| `firstLineIndentCm` | число | да | Отступ первой строки в сантиметрах, 0–10 |
| `lineSpacing` | число | да | Межстрочный интервал (множитель), 0.5–3 |
| `spaceBeforePt` | число | да | Интервал до абзаца в пунктах, 0–200 |
| `spaceAfterPt` | число | да | Интервал после абзаца в пунктах, 0–200 |

### `page` — страница

| Поле | Тип | Обязательное | Значения |
|---|---|---|---|
| `format` | строка | да | `A4`, `A5`, `A3`, `Letter`, `Legal` |
| `orientation` | строка | да | `portrait` (книжная), `landscape` (альбомная) |
| `marginsMm` | объект | да | `left`, `right`, `top`, `bottom` в миллиметрах, 0–100 |
| `headerMm` | число | да | Расстояние до верхнего колонтитула, мм |
| `footerMm` | число | да | Расстояние до нижнего колонтитула, мм |

### `body` — основной текст

Все поля из «общих полей оформления абзаца» плюс:

| Поле | Тип | Обязательное | Описание |
|---|---|---|---|
| `removeItalic` | логическое | нет | Снимать курсив (по умолчанию `true`) |
| `removeUnderline` | логическое | нет | Снимать подчёркивание (по умолчанию `true`) |

Полужирный в основном тексте принудительно не снимается: профиль задаёт
оформление по умолчанию, а прямое выделение автора сохраняется. Курсив
и подчёркивание снимаются, потому что это отдельное требование методичек;
каждое такое место попадает в отчёт.

### `headings` — заголовки

| Поле | Тип | Обязательное | Описание |
|---|---|---|---|
| `maxLevel` | целое | да | Сколько уровней описано профилем, 1–9 |
| `noHyphenation` | логическое | нет | Запрещать переносы в заголовках |
| `structural` | объект | да | Оформление структурных частей (ВВЕДЕНИЕ, ЗАКЛЮЧЕНИЕ и подобных) |
| `levels` | объект | да | Ключи `"1"`…`"maxLevel"` — оформление уровней |

Дополнительные поля объекта `structural`:

| Поле | Тип | Описание |
|---|---|---|
| `titles` | список строк | Названия структурных частей, например `ВВЕДЕНИЕ`. Совпадение проверяется без учёта регистра; допускается короткое уточнение: «ПРИЛОЖЕНИЕ А» |
| `uppercase` | логическое | Печатать прописными (включается оформлением Word, текст документа не меняется) |

Правило: в `levels` должны быть описаны **все** уровни от 1 до `maxLevel`.

### `captions` — подписи

Объект с двумя полями: `figure` (подписи рисунков) и `table` (названия таблиц).
В каждом — поля оформления абзаца плюс:

| Поле | Тип | Описание |
|---|---|---|
| `noHyphenation` | логическое | Запрещать переносы в подписи |
| `position` | строка | Где должна стоять подпись: `below` (под элементом), `above` (над элементом), `keep` (не переносить). По умолчанию `keep` |

Как работает `position`:

- `below` для `figure` — подпись рисунка ставится **под** рисунком;
- `above` для `table` — название таблицы ставится **над** таблицей;
- если подпись уже стоит правильно, ничего не происходит;
- если подпись стоит не рядом со своим рисунком или таблицей, приложение
  её не трогает;
- если рядом оказались две подписи, приложение отказывается угадывать
  и выносит это место в раздел «Требует ручной проверки»;
- каждое перемещение записывается в отчёт.

Это единственное правило, которое меняет порядок элементов документа,
поэтому по умолчанию (`keep`) оно выключено и включается только профилем.

### `figures` — рисунки

Раздел необязательный: если его нет, рисунок ставится по центру.

| Поле | Тип | По умолчанию | Описание |
|---|---|---|---|
| `alignment` | строка | `center` | Выравнивание абзаца с рисунком: `left`, `center`, `right`, `justify` |
| `lineSpacing` | число | `1.0` | Межстрочный интервал абзаца с рисунком |
| `spaceBeforePt` | число | `0` | Интервал перед рисунком |
| `spaceAfterPt` | число | `0` | Интервал после рисунка |

Отступ первой строки у абзаца с рисунком **снимается всегда**, независимо
от выравнивания. Причина простая: абзац с картинкой обычно не имеет
собственных свойств и наследует отступ от стиля «Обычный», которому правило
основного текста задаёт отступ 1,25 см. Из-за этого рисунок смещается вправо —
даже когда задано выравнивание по центру.

### `tables` — таблицы

| Поле | Тип | Описание |
|---|---|---|
| `font` | строка или `null` | Шрифт текста в ячейках |
| `fontSizePt` | число | Размер шрифта в ячейках |
| `lineSpacing` | число | Межстрочный интервал в ячейках |
| `firstLineIndentCm` | число | Отступ первой строки в ячейках (обычно 0) |
| `headerRowAlign` | строка | Выравнивание первой строки (шапки) |
| `numericCellAlign` | строка | Выравнивание числовых ячеек |
| `textCellAlign` | строка | Выравнивание текстовых ячеек |
| `markerCells` | список строк | Значения, которые считаются прочерком: их выравнивание не меняется. Обычно `["", "–", "-", "—", "х", "x"]` |
| `preferredWidth` | строка, необязательное | `auto` — снять заданную ширину таблицы, `keep` (по умолчанию) — не трогать |
| `indentCm` | число, необязательное | Отступ таблицы от левого поля. Если поле не указано, отступ не меняется |

Поля `preferredWidth` и `indentCm` отвечают за то, чтобы таблица не уезжала
вправо:

- `preferredWidth: "auto"` — это снятая галочка **«Ширина»** в окне
  «Свойства таблицы» на вкладке «Таблица»: ширина не задана, Word подбирает
  её по содержимому;
- `indentCm: 0` — таблица стоит вплотную к левому полю, без отступа.

Если в документе оказалось два элемента ширины (`w:tblW`), лишний удаляется:
иначе неизвестно, какое значение считать настоящим.

Числовой считается ячейка, содержимое которой — число, возможно с знаком,
разделителем разрядов, запятой как десятичным разделителем и единицей
измерения (`55000`, `1 234,5`, `−12,5 %`, `7 шт.`). Диапазоны (`2020-2022`)
числами не считаются.

### `footnotes` — сноски

| Поле | Тип | Описание |
|---|---|---|
| `font` | строка или `null` | Шрифт сносок |
| `fontSizePt` | число | Размер шрифта сносок |
| `lineSpacing` | число | Межстрочный интервал сносок |

Оформление задаётся определением стиля сносок — надёжнее, чем правка самих
сносок по одной.

### `lists` — перечисления

| Поле | Тип | Описание |
|---|---|---|
| `applyParagraphFormatting` | логическое | Оформлять ли абзацы элементов перечислений |
| `replaceMarkers` | логическое | Заменять ли маркеры и нумерацию (в MVP не поддерживается, оставлено в формате) |
| `firstLineIndentCm` | число | Отступ первой строки элемента перечисления |

### `pageNumbers` — нумерация страниц

| Поле | Тип | Описание |
|---|---|---|
| `enabled` | логическое | Включена ли нумерация |
| `position` | строка | `bottom-center`, `bottom-left`, `bottom-right`, `top-center`, `top-left`, `top-right` |
| `font` | строка или `null` | Шрифт номера |
| `fontSizePt` | число | Размер шрифта номера |
| `skipFirstPage` | логическое | Не ставить номер на первой странице (титульном листе) |

Номер ставится полем Word `PAGE`, а не текстом. Нумерация делается сквозной:
сбросы нумерации в разделах снимаются.

### `hyphenation` — переносы

| Поле | Тип | Описание |
|---|---|---|
| `enabled` | логическое | Включить автоматическую расстановку переносов |
| `excludeHeadings` | логическое | Не переносить слова в заголовках |
| `excludeCaptions` | логическое | Не переносить слова в подписях |

### `blankLines` — свободные строки

| Поле | Тип | Описание |
|---|---|---|
| `insert` | логическое | Вставлять пустые абзацы там, где требует оформление |
| `style` | строка | `body` (как основной текст) или `single` (одинарный интервал) |

## Строгость проверки

Проверка профиля намеренно строгая:

- **неизвестное поле — ошибка**, потому что опечатка в имени поля молча
  привела бы к неверному оформлению документа;
- значения проверяются по диапазонам и спискам допустимых значений;
- все обязательные поля должны быть заполнены;
- сообщение об ошибке указывает путь поля, например:
  `body.alignment: может быть только одним из: left, center, right, justify. Получено: «по ширине»`.

Тексты сообщений — на русском, потому что их читает пользователь.

## Пример минимального профиля

```json
{
  "id": "my-department-2026",
  "name": "Моя кафедра — требования 2026",
  "version": "1.0.0",
  "demo": false,
  "source": { "title": "Методические указания кафедры", "year": 2026 },
  "appliesTo": ["курсовая работа"],
  "page": {
    "format": "A4",
    "orientation": "portrait",
    "marginsMm": { "left": 30, "right": 15, "top": 20, "bottom": 20 },
    "headerMm": 20,
    "footerMm": 12.5
  },
  "body": {
    "font": "Times New Roman",
    "sizePt": 14,
    "alignment": "justify",
    "firstLineIndentCm": 1.25,
    "lineSpacing": 1.5,
    "spaceBeforePt": 0,
    "spaceAfterPt": 0,
    "removeItalic": true,
    "removeUnderline": true
  },
  "headings": {
    "maxLevel": 2,
    "noHyphenation": true,
    "structural": {
      "titles": ["ВВЕДЕНИЕ", "ЗАКЛЮЧЕНИЕ"],
      "uppercase": true,
      "alignment": "center",
      "firstLineIndentCm": 0,
      "sizePt": 14,
      "bold": true,
      "lineSpacing": 1.0,
      "spaceBeforePt": 0,
      "spaceAfterPt": 0
    },
    "levels": {
      "1": {
        "alignment": "justify", "firstLineIndentCm": 1.25, "sizePt": 14,
        "bold": true, "lineSpacing": 1.0, "spaceBeforePt": 0, "spaceAfterPt": 0
      },
      "2": {
        "alignment": "justify", "firstLineIndentCm": 1.25, "sizePt": 14,
        "bold": true, "lineSpacing": 1.0, "spaceBeforePt": 0, "spaceAfterPt": 0
      }
    }
  },
  "captions": {
    "figure": {
      "alignment": "center", "firstLineIndentCm": 0, "sizePt": 14,
      "lineSpacing": 1.0, "spaceBeforePt": 0, "spaceAfterPt": 0, "noHyphenation": true
    },
    "table": {
      "alignment": "left", "firstLineIndentCm": 0, "sizePt": 14,
      "lineSpacing": 1.0, "spaceBeforePt": 0, "spaceAfterPt": 0, "noHyphenation": true
    }
  },
  "tables": {
    "font": "Times New Roman", "fontSizePt": 12, "lineSpacing": 1.0,
    "firstLineIndentCm": 0, "headerRowAlign": "center",
    "numericCellAlign": "center", "textCellAlign": "left",
    "markerCells": ["", "–", "-", "—", "х", "x"]
  },
  "footnotes": { "font": "Times New Roman", "fontSizePt": 10, "lineSpacing": 1.0 },
  "lists": { "applyParagraphFormatting": true, "replaceMarkers": false, "firstLineIndentCm": 1.25 },
  "pageNumbers": {
    "enabled": true, "position": "bottom-center",
    "font": "Times New Roman", "fontSizePt": 12, "skipFirstPage": true
  },
  "hyphenation": { "enabled": true, "excludeHeadings": true, "excludeCaptions": true },
  "blankLines": { "insert": true, "style": "body" }
}
```

Проверить свой профиль можно командой:

```bash
python main.py --profiles-dir путь/к/папке/с/профилями --list-profiles
```
